# 🛡️ Dalelak Pitch Showcase & Anti-Theft Studio (Phase 3)
### استوديو العروض الترويجية والإغلاق البيعي المحمي لمنظومة دليلك

تطبيق ويب مستقل (Satellite Web App) يعمل كـ **ماكينة إغلاق بيعي ذاتي**، حيث يجمع مخرجات التسويق والهوية البصرية ويولد صفحة استعراض تفاعلية مبهرة مخصصة لصاحب النشاط التجاري على هاتفه، محمية بـ 3 طبقات ضد السرقة مع تتبع لحظي للاهتمام وإمكانية الترقية للسيرفر الأساسي.

---

## 🚀 المميزات الرئيسية

1. **العرض التفاعلي المبهر للعميل (Client Teaser)**:
   - مجسم ستاند طاولة أكريليكي ثلاثي الأبعاد فاخر (3D Luxury Stand) يحمل اسم المحل وكود QR مباشر لتقييمات Google Maps.
   - توقعات نمو وتصدر خرائط Google بالمنطقة.
   - نموذج منشورات سوشيال ميديا موحدة بهوية النشاط.
   - عينة من خطة المحتوى التسويقي لـ 30 يوماً.
   - باقة الخصم الاستثنائي مع عداد زمني تنازلي مباشر (48 ساعة).
   - زر تحويل مباشر لحجز الباقة عبر واتساب دليلك.

2. **3 طبقات حماية ضد السرقة (3-Layer Anti-Theft)**:
   - **الطبقة 1**: علامة مائية شبكية ديناميكية مائلة متكررة على كامل الصفحة تحوي كود العرض واسم النشاط.
   - **الطبقة 2**: درع برامجي لمنع النسخ وحظر النقر بالزر الأيمن وحظر اختصارات الحفظ والطباعة (Ctrl+S / Ctrl+P).
   - **الطبقة 3**: حجب الدقة العالية للملفات والأصول حتى الاعتماد الرسمي.

3. **رادار التتبع اللحظي (Live Engagement Radar)**:
   - مراقبة لحظة فتح العميل للرابط، ومدة تصفحه، والأقسام الأكثر جذباً لاهتمامه (ستاند الأكريليك، الأسعار، السوشيال ميديا).
   - احتساب مقياس التفاعل الذكي وتنبيهات فورية للمندوب.

4. **صانع رسائل الواتساب النفسية**:
   - 3 نصوص تسويقية باللهجة المصرية مدروسة بعناية (فرصة الصدارة، الهدية الترويجية، الخصم المؤقت).
   - رابط فتح مباشر للواتساب بضغطة زر.

5. **ترقية النشاط للسيرفر الأساسي (Core Promotion)**:
   - ترحيل العميل وبيانات التعاقد والفاتورة الرسمية إلى قاعدة بيانات دليلك التشغيلية (`Supabase Core`).
